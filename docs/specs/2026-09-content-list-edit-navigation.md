# 콘텐츠 목록 수정 화면 이동 스펙

- 상태: 구현 완료
- 작성일: 2026-09-30
- 담당: Codex

## 배경과 목적

목록에서 콘텐츠 행을 선택해 해당 콘텐츠의 작성 화면으로 이동할 수 있도록 합니다.

## 범위

### 포함

- 콘텐츠 행 클릭 시 작성 화면으로 이동합니다.
- 선택한 콘텐츠 ID를 `id` query string으로 전달합니다.
- 작성 화면은 ID가 있으면 상세를 조회해 카테고리, 제목, 내용, 링크에 채웁니다.
- 편집 중 헤더의 발행하기는 `PutContentsDetail`로 수정 내용을 저장한 뒤 발행 설정 모달을 엽니다.
- 기존 콘텐츠가 `public`이면 알람 설정 모달을 건너뛰고 목록으로 돌아갑니다.
- 모달 진입 시 기존 알람을 조회해 발송 여부, 대상, 제목을 적용합니다.
- 조회 결과의 `content_status`가 `public`이면 공개, `content_status`가 `private`이고 `send_status`가 `pending`이면 예약 상태를 선택합니다.
- 알람 조회 결과의 `data`가 `null`이면 비공개를 선택합니다.
- 기존 알람이 조회되면 저장 시 해당 알람을 수정 API로 갱신합니다.
- 푸시 알람 생성 버튼은 행 클릭과 분리해 자체 동작을 유지하고, 콘텐츠 ID를 `content_id` query로 전달합니다.

## 사용자 흐름

1. 사용자가 콘텐츠 행을 클릭합니다.
2. `/notice/contents/write?id={id}`로 이동합니다.
3. 해당 ID의 콘텐츠가 작성 폼에 표시됩니다.
4. 헤더의 발행하기를 누르면 수정 API가 호출됩니다. 콘텐츠가 기존 `public`이면 목록으로 돌아가고, 그 외 상태는 발행 설정 모달을 표시합니다.
5. 행의 푸시 알람 생성 버튼을 클릭하면 콘텐츠 ID를 `content_id` query로 전달해 알람 작성 화면으로 이동합니다.

## 요구사항

- 행은 마우스 클릭과 키보드 Enter/Space로 열 수 있습니다.
- 푸시 알람 생성 버튼 클릭 이벤트는 행 클릭으로 전파되지 않습니다.
- `id` query 값이 없으면 새 콘텐츠 작성 폼을 표시합니다.
- 콘텐츠 조회 실패 시 오류를 표시하고, 조회 중에는 진행 상태를 표시합니다.

## 예외 및 실패 처리

- 콘텐츠 ID는 URL에 넣기 전 문자열로 변환하고 인코딩합니다.
