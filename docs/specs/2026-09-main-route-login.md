## 배경과 목적

사이트 메인 경로에 접근했을 때 기본 안내 화면 대신 로그인 화면을 표시합니다.

## 범위

### 포함

- `/`에 접속하면 `/login`으로 이동합니다.

### 제외

- 이미 로그인한 사용자의 자동 콘텐츠 목록 이동
- 로그인 및 인증 흐름 변경

## 사용자 흐름

1. 사용자가 사이트 메인 경로(`/`)에 접근합니다.
2. 로그인 화면(`/login`)으로 이동합니다.

## 요구사항

- 메인 페이지 렌더링 단계에서 `/login`으로 리다이렉트합니다.
