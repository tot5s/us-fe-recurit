# 콘텐츠 발행 및 알람 설정 스펙

- 상태: 구현 완료
- 작성일: 2026-09-29
- 담당: Codex

## 배경과 목적

필수 입력값을 확인하고 콘텐츠 생성 후 발송 여부에 따라 알람을 설정하거나 삭제합니다.

## 범위

### 포함

- 카테고리, 제목, 내용만 필수값으로 확인합니다.
- 필수값이 입력되지 않으면 콘텐츠 작성 화면의 발행하기 버튼을 비활성화합니다.
- 헤더에서 발행하기를 누르면 발행 설정 모달을 엽니다.
- 모달의 최종 발행 버튼에서 콘텐츠를 생성하고 공개 상태, 예약 설정, 알람 설정을 저장합니다.

### 제외

- 링크 입력 여부에 따른 버튼 활성화 검증

## 사용자 흐름

1. 사용자가 카테고리를 하나 이상 선택하고 제목과 내용을 입력합니다.
2. 필수값이 모두 입력되면 발행하기 버튼이 활성화됩니다.
3. 발행하기를 누르면 발행 설정 모달이 열립니다.
4. 공개 상태, 예약 시간, 알람 발송 여부를 선택합니다.
5. 최종 발행 버튼에서 콘텐츠 생성 후 공개 상태, 예약, 알람 설정을 저장합니다.
6. 발행 설정 저장이 성공하면 콘텐츠 목록으로 돌아갑니다.

## 요구사항

- 오타가 있던 discript 상태는 description으로 정리합니다.
- 카테고리는 1개 이상, 최대 3개까지 선택해야 합니다.
- 제목과 내용은 공백만 입력한 경우 미입력으로 판단합니다.
- 링크는 선택 항목이며 필수값 검사에 포함하지 않습니다.
- 콘텐츠 생성 또는 후속 설정 저장에 실패하면 모달에 오류를 표시하고 재시도할 수 있습니다.
- 생성된 콘텐츠 ID를 보관해 후속 설정 저장 실패 시 콘텐츠가 중복 생성되지 않도록 합니다.
- 알람을 발송으로 설정하면 대상과 알람 제목을 지정합니다.
- 발송을 선택하고 설정을 저장하면 SetNotificationFn을 호출합니다.
- 미발송을 선택하고 설정을 저장하면 연결된 알람이 있을 때 DelNotificationDetailFn을 호출합니다.
- 예약 발행은 예약 날짜가 입력되어야 저장할 수 있습니다.
- 발송은 알림 제목이 입력되어야 저장할 수 있습니다.
- 발송 제목이 비어 있으면 입력 아래에 `필수 정보입니다`와 `border-rose-500`을 표시합니다.
- 예약 발행 시간이 비어 있으면 입력 아래에 `시간을 다시 선택해주세요`와 `border-rose-500`을 표시합니다.
- 공개와 비공개는 예약 날짜를 필수로 요구하지 않습니다.
- 공개 상태에서 알람 발송을 선택하면 알람 `scheduled_at`은 현재 시각에서 10초 뒤로 설정합니다.
- 기존 알람을 수정할 때도 같은 `scheduled_at`을 알람 예약 API에 전달합니다.
- 이미 `public` 상태인 수정 콘텐츠는 알람 설정 모달을 건너뛰고 콘텐츠 목록으로 돌아갑니다.

## 예외 및 실패 처리

- 필수값이 하나라도 없으면 버튼을 비활성화하고 모달을 열 수 없습니다.
