# 알람 작성 스펙

- 상태: 구현 완료
- 작성일: 2026-09-30
- 담당: Codex

## 배경과 목적

알람을 작성할 때 발송 대상, 제목, 발송 시간을 입력하고 작성 중단을 확인할 수 있도록 합니다.

## 범위

### 포함

- 대상자, 제목, 시간 입력 상태를 공통 알람 작성 컨텍스트에서 관리합니다.
- 작성 화면에 처음 진입하면 대상자를 전체(`all`)로 선택합니다.
- 알람 목록 행 선택 시 상세 정보와 예약 시간을 조회해 수정 폼에 적용합니다.
- 콘텐츠의 푸시 알람 설정 진입은 `content_id`를 전달해 신규 알람을 작성합니다.
- 연결된 콘텐츠가 공개 상태가 아니면 알람 생성/수정 전에 알람 발송 시간으로 콘텐츠 예약을 설정합니다.
- 저장 성공 후 알람 목록으로 돌아갑니다.
- 필수 정보가 빠진 상태에서 헤더의 발행하기를 누르면 안내 문구를 표시합니다.
- 작성 화면의 뒤로가기 동작에서 종료 확인 모달을 표시합니다.

## 사용자 흐름

1. 알람 작성 화면에서 대상자, 제목, 시간을 입력합니다.
2. 필수값이 모두 있으면 발행하기를 눌러 알람을 생성하거나 수정합니다.
3. 필수값이 빠졌으면 발행하기 클릭 시 필수 정보 입력 안내를 표시합니다.
4. 뒤로가기 클릭 시 확인 모달에서 예를 누르면 입력을 초기화하고 알람 목록으로 이동하며, 아니오를 누르면 작성 화면에 남습니다.

## 요구사항

- 대상자, 제목, 발송 시간을 필수값으로 취급합니다.
- 기본 대상자 값은 `all`이며 작성 종료 후 초기화할 때도 `all`로 되돌립니다.
- 필수값 누락 안내는 입력을 수정하면 사라집니다.
- 제목과 시간 누락 경고는 각 입력 컴포넌트의 제목 옆에 표시하고, 해당 입력 테두리를 rose 색상으로 표시합니다.
- 종료 확인 모달에 예/아니오 버튼을 제공합니다.
- 편집 조회에는 `GetNotificationDetailFn`, `GetNotificationScheduleFn`을 사용합니다.
- 수정 시 예약 API와 `PutNotificationDetailFn`을 호출합니다.
- 신규 생성 시 `SetNotificationFn` 호출 후 생성된 알람 ID로 예약 API를 적용합니다.
- 콘텐츠가 비공개이면 상태를 private로 저장한 뒤, 알람이 기존에 있으면 `PutContentsSceduleFn`, 없으면 `SetContentsSceduleFn`으로 콘텐츠 예약을 설정한 후 알람 API를 호출합니다.
- 예약 API가 과거 발행 이력 때문에 예약할 수 없다고 응답하면 콘텐츠를 public으로 전환한 후 알람 API를 호출합니다.
- 기존 콘텐츠 예약 수정 API의 `published_at`은 초 단위까지 `YYYY-MM-DDTHH:mm:ss` 형식으로 전달합니다.
- 날짜/시간 입력값에 초가 없으면 상태값에 `:00`초를 붙입니다.
