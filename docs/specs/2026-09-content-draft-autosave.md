# 콘텐츠 임시 저장 스펙

- 상태: 구현 완료
- 작성일: 2026-09-30
- 담당: Codex

## 배경과 목적

새 콘텐츠 작성 중 입력한 내용을 브라우저 로컬 스토리지에 임시 저장해 작성 중단 후 이어 쓸 수 있게 합니다.

## 범위

### 포함

- 헤더의 임시저장 버튼으로 현재 새 콘텐츠를 저장합니다.
- 저장 성공 시 완료 토스트를 잠시 표시하고, 임시저장 버튼에는 포인터 커서를 표시합니다.
- 작성 화면 헤더의 콘텐츠 쓰기 버튼은 콘텐츠 목록으로 이동합니다.
- 새 콘텐츠 작성 화면에서 30분마다 자동 저장합니다.
- 임시 저장 데이터는 로컬 스토리지의 단일 키에 보관해 한 개만 유지합니다.
- 새 콘텐츠 작성 진입 시 저장된 글이 있으면 불러오기 또는 새 글 작성을 선택하는 모달을 표시합니다.
- 선택 모달은 400px 너비로 `새글 쓰기` 제목과 닫기 버튼, 펜/말풍선 아이콘 항목 및 보조 문구를 표시합니다. 임시 저장 항목에는 저장 시각을 `YYYY년 MM월 DD일 HH:mm` 형식으로 표시합니다.
- 콘텐츠 발행이 완료되면 임시 저장 데이터를 삭제합니다.

### 제외

- 기존 콘텐츠 편집 내용의 임시 저장
- 서버 동기화

## 사용자 흐름

1. 새 콘텐츠를 작성하며 헤더 임시저장 버튼을 누르거나 30분 자동 저장을 기다립니다.
2. 브라우저 로컬 스토리지에 카테고리, 제목, 내용, 링크를 저장합니다.
3. 다음 새 콘텐츠 작성 진입 시 저장된 글이 있으면 이어 작성 또는 새 글 작성을 선택합니다.
4. 발행이 완료되면 임시 저장 데이터를 삭제합니다.

## 요구사항

- 저장 키를 하나만 사용해 최신 임시 저장 글 한 개만 보관합니다.
- 임시 저장 데이터에는 저장 시각과 작성 필드를 포함합니다.
- 수정 화면에서는 새 콘텐츠 임시 저장을 수행하지 않습니다.
